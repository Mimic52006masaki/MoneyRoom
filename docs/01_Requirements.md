# アプリ要件定義

## 1. 目的・背景
- このアプリで解決したい課題：
  - 子どもたちのお小遣いを管理する仕組みがなく、口頭での管理や紙ベースの記録では混乱が生じる
  - 貯金目標や支出履歴を可視化して金銭感覚を育てたい
- なぜ今このアプリが必要か：
  - 家庭内での金銭教育のサポート
  - 兄弟間での割り振り管理を簡単にしたい

## 2. ゴール
- このアプリが「成功」と判断できる状態：
  - 子どもたちが自分のお小遣い残高や貯金目標を確認できる
  - 兄弟間での割り振り金額が自動計算され、ミスなく反映される
  - 支出の入力・削除・編集が直感的に行える

## 3. 想定ユーザー
- 主なユーザー：
  - 小学5年生〜中学1年生の兄弟姉妹
- 利用シーン：
  - 自宅でお小遣いの残高や支出を確認・管理する
  - 欲しいもののために貯金目標を設定する

## 4. 機能一覧
### Must（必須）
- ユーザーごとの所持金管理
- 支出・入金の記録（タイトル・金額・カテゴリー）
- 削除・編集機能
- ダッシュボードで兄弟全体の所持金表示
- 割り振り金額計算（中学生ユーザー用）
- 貯金目標設定・達成度表示

### Nice to Have（あれば良い）
- 支出履歴のグラフ表示
- バッジやアニメーションによる達成感演出

## 5. 対応プラットフォーム
- Web（Vercelデプロイ想定）
- スマホ・タブレットでも閲覧可能なレスポンシブ対応

## 6. 対象外（やらないこと）
- ユーザー認証やログイン管理
- 外部サービス連携（決済・銀行口座）
