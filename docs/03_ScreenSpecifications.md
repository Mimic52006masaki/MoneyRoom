# 画面仕様・画面遷移

## 画面一覧
1. ダッシュボード（兄弟全体の所持金表示）
2. 個人画面（支出・入金管理、貯金目標設定）
3. 割り振り管理画面（中学生ユーザーのみ）

## 各画面の仕様

### ダッシュボード
- **ルート**: `/dashboard`
- **表示内容**:
  - 兄弟全員の名前と所持金（カードレイアウト）
  - 総所持金
  - 貯金目標金額
- **操作**:
  - 個人画面への遷移（各ユーザーカードクリック）
  - 割り振り管理画面への遷移
- **デザイン**: Tailwind CSS を使用したレスポンシブグリッドレイアウト

### 個人画面
- **ルート**: `/user/[id]`
- **表示内容**:
  - ユーザーの名前と所持金残高
  - 貯金目標金額
  - 支出・入金の履歴リスト（日時順）
- **入力項目**:
  - タイプ（支出/入金）
  - 金額
  - 項目（購入品名など）
  - カテゴリー
  - 貯金目標金額
- **操作**:
  - 支出・入金の追加
  - 貯金目標の更新
  - 取引履歴の削除

### 割り振り管理画面
- **ルート**: `/allocation`
- **表示内容**:
  - 兄弟一覧（ドロップダウン）
  - 割り振り履歴
- **入力項目**:
  - 送り元ユーザー
  - 送り先ユーザー
  - 割り振り金額
- **操作**:
  - 割り振りの実行
  - 履歴の確認

## 画面遷移
- ホームページ → ダッシュボード（自動リダイレクト）
- ダッシュボード → 個人画面
- ダッシュボード → 割り振り管理画面
- 個人画面 → ダッシュボード（ブラウザバック）

## 共通仕様
- **レスポンシブ対応**: Tailwind CSS を使用したモバイル・デスクトップ対応
- **リアルタイム更新**: Firestore を使用したデータ同期
- **エラーハンドリング**: 入力バリデーションとエラーメッセージ表示
