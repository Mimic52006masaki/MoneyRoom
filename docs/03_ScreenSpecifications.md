# 画面仕様・画面遷移

## 画面一覧
1. ダッシュボード（兄弟全体の所持金表示）
2. 個人画面（支出・入金管理）
3. 割り振り管理画面（中学生ユーザーのみ）
4. 貯金目標画面
5. 設定画面（ユーザー追加・編集）

## 各画面の仕様

### ダッシュボード
- 表示内容：
  - 兄弟全員の名前と所持金
  - 総所持金
- 操作：
  - 個人画面への遷移

### 個人画面
- 表示内容：
  - 所持金残高
  - 支出・入金の履歴リスト
- 入力項目：
  - タイトル（購入品名）
  - 金額
  - カテゴリー
- 操作：
  - 支出・入金の追加・編集・削除

### 割り振り管理画面
- 表示内容：
  - 兄弟一覧
  - 割り振り可能な総額
- 入力項目：
  - 割り振り金額
- 操作：
  - 割り振りの実行
  - 履歴の確認

### 貯金目標画面
- 表示内容：
  - 設定済み目標金額
  - 達成度ゲージ
- 操作：
  - 目標金額の設定・更新

## 画面遷移
- ダッシュボード → 個人画面
- 個人画面 → 割り振り管理画面（中学生ユーザーのみ）
- 個人画面 → 貯金目標画面
